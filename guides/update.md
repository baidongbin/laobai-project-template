# 更新已接入项目的模板规则

适用于已经使用本模板、希望吸收后续改进的项目；首次接入使用 [接入指南](adopt.md)，文档拆分使用 [升级指南](lite-to-standard.md)。不要求保存模板版本号，也不使用自动覆盖工具。

在目标项目打开 Agent，填写路径和更新范围后发送：

```text
模板仓库：<模板仓库的绝对路径>
目标项目：<目标项目的绝对路径>
更新范围：<需要吸收的规则或改进；不明确时先比较并建议>

请只读参考模板仓库 guides/project-options.md，按指定范围增量更新目标项目的协作文档。
先核对目标项目规则、分支、工作区及现有文档职责，不用整份模板覆盖项目内容。
保留已确定的文档基线、源码导出和 Git 策略，不要求重新选择；没有选择标记不代表未配置。
仅对新增选项或实质冲突集中询问，说明原策略、建议变化和影响；等待时继续不依赖答案的检查。
在授权范围内合并有关改进，保留业务事实、定制规则、历史证据和他人修改，不按模板预设重置项目。
不启用的选项不引入对应脚本、核对章节或失效链接；未获授权不删除已有文件或记录。
目标项目只保留确定后的规则，不携带选项菜单、OPTIONAL 标记或日常重复确认流程。
文档基线已启用时保留现有基线和累计缺口，不因模板更新自动推进。
检查受影响的相对链接、状态与规则冲突，运行与修改有关的安全验证。
报告保留的选择、实际修改、检查结果和未覆盖项。
本轮只更新协作文档与已明确选择的模板工具，不安装依赖、不修改业务、不部署，
不执行 commit 或 push；本轮限制不改写项目长期 Git 策略。
```

用户另有明确的本轮提交推送授权时以用户指令为准。模板更新完成后，日常开发继续执行项目已确定的规则，不重新询问设置。
